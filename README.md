# graph-ontology
Initial Commit includes three JSON graph ontologies developed through LLM work.

The ontologies are meant to be provided to an LLM and provide a systems framework for modeling source -> signal -> receiver relationships from a physicalist position.

The initial commits are first-drafts of the graph ontology approach, and are not yet consistent internally, or with each other. There are dangling edges and incorrect labels.

Ongoing replacement work is focusing on a multi-agent architecture that is tasked with maintaining a "Graph of Graphs" to serve as a graph ontology memory and reasoning system.

This system will no longer push individual files where the ontology exists, but will instead maintain a database where schemas, ontologies and glossaries are registered: where specialized agents maintain registration & connection after being provided graph summaries by agents that have used the system as a resource.

The initial ontology files are, therefore, a temporary memory store of work up until this point. It is for this reason that no attempt has been made to repair their initial deficiencies.
